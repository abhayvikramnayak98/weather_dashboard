# Changelog

All notable changes to Weather Dashboard are documented in this file.

## \[1.0.0\] - Stable Release

### Added

-   Desktop weather dashboard application.
-   Location search and geocoding workflow.
-   Current weather conditions.
-   Daily weather forecast.
-   Hourly weather forecast.
-   Air-quality and related weather information.
-   Weather detail sections for wind, precipitation, and other
    conditions.
-   Responsive dashboard layouts for different window sizes.
-   Scrollable dashboard content where required.

### Search and interaction

-   Compact location-search interface.
-   Improved search typography.
-   Search-result highlighting.
-   Keyboard navigation with `Up` and `Down`.
-   `Enter` to select the highlighted location.
-   `Esc` to close the search results.
-   Mouse-based result selection.
-   Bold typography for the active search result.
-   Regular typography for inactive search results.

### UI polish

-   Refined title and search-area spacing.
-   Improved header proportions.
-   Consistent section spacing.
-   Improved behavior across wide, medium, and narrow layouts.
-   Preserved appropriate scrolling behavior for dashboard content.

### Release status

Version **1.0.0** is the first stable release and represents the
completed baseline for future development.
